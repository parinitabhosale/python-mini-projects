# Python Mini Projects

Small beginner Python projects built while learning the language, using Jupyter Notebook.

## 1. BMI Calculator
A program that asks for a person's name, weight (pounds) and height (inches), calculates their BMI and prints the weight category.

- Formula used: BMI = (weight in pounds x 703) / (height in inches x height in inches)
- Categories: Underweight, Normal weight, Overweight, Obese, Severely Obese, Morbidly Obese
- Concepts practised: user input, type conversion, arithmetic, if/elif conditions
- File: `BMI_Calculator.ipynb`

## 2. Automatic File Sorter
A script that organises a messy folder by file type. It creates the folders `xlsx files`, `image files` and `text files` if they don't exist, then moves each .xlsx, .jpg and .txt file into the matching folder.

- Concepts practised: working with files and folders using the `os` and `shutil` libraries, loops, conditions
- Note: set the `path` variable to your own folder before running. Try it on a test folder first, since it moves files.
- File: `Automatic_File_Sorter_In_File_Explorer.ipynb`

## Tools
